# Hugging Face Model Interaction App

This Streamlit app allows users to interact with Hugging Face and other AI API models. Users can select a model, input text, and receive predictions.

## Features
- Interact with Hugging Face API models
- Local model inference using Transformers library
- User-friendly interface with Streamlit

## Setup
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `streamlit run app.py`

## Notes
- Replace `YOUR_HUGGINGFACE_API_KEY` with your actual Hugging Face API key in `app.py`.
- Ensure you have the necessary models downloaded for local inference.
